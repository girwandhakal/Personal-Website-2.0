Projects / Portfolio assistant

A chatbot that answers questions about my work

I built a chatbot for an earlier version of this portfolio. I wanted visitors to be able to ask about a project or find out where I’d used a tool without looking through every page.

AI systems · Backend engineering
Tools: TypeScript, Next.js, Prisma, Groq, Python, Presidio, AES-256-GCM

Starting with my own notes

I wrote notes about my projects and experience so the chatbot had something specific to look up when someone asked a question.

Finding the right notes

The app picks out terms in the question, scores notes by matching words, tags, and project names, and sends the closest matches to the model. My collection was small enough that I could check why a given note came back.

Handling messages

I added request limits and a check for sensitive information. The app encrypts the message text it saves. While answering, it sends the necessary text to the model provider.

When I’d change the search

I’d start by trying questions visitors actually ask. If the chatbot routinely misses the right notes, I’d have examples to use when testing a different search method.

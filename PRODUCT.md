# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primarily recruiters evaluating Girwan Dhakal for engineering and machine learning opportunities (confirmed by the user).

## Product Purpose

Present Girwan's engineering projects, research, experience, and qualifications so recruiters can evaluate his work and contact him.

## Capabilities and Constraints

Existing Next.js portfolio with project detail views, résumé access, contact form, and an AI chat interface. Preserve factual content, working links, and these capabilities throughout the requested complete UI redesign. Project and profile source files are the factual authority; do not add unverified achievements.

## Brand Commitments

Girwan Dhakal. The user requests a complete visual redesign with ambitious interactive UI, animation, and microinteractions.

Keep visible wording as minimal as possible, like the existing website. Use plain labels rather than invented design names. Detailed evidence belongs in optional project exploration, not dense homepage copy. The user requested a safer visual selection during the first comparison round; this is session steering rather than a permanent ban on expressive design.

## Evidence on Hand

`src/content/profile.ts` contains education, experience, skills, and outcomes. `src/content/projects.ts` contains project summaries and detailed case studies. Existing résumé links and contact information are available in the profile.

## Product Principles

- Make qualifications and evidence easy for recruiters to assess.
- Let visitors explore the actual engineering work.
- Preserve factual accuracy and access to contact and résumé.
